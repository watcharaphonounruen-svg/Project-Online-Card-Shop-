# รายละเอียดโครงงาน CARD HAVEN

## 1. ชื่อระบบ

## 2. สมาชิก

## 3. วัตถุประสงค์
1. เพื่อพัฒนาเว็บไซต์ร้านค้าการ์ดสะสมออนไลน์
2. เพื่อให้ผู้ใช้สามารถค้นหา เลือกดู และสั่งซื้อการ์ดสะสมได้
3. เพื่อให้ผู้ดูแลระบบสามารถเพิ่ม แก้ไข และจัดการสินค้าได้

5. เพื่อศึกษาการจัดการ Cookie, Session และการกำหนดสิทธิ์ผู้ใช้งาน

## 4. Features (ความสามารถของระบบ)

### ผู้ใช้ทั่วไป (User)
- สมัครสมาชิกและเข้าสู่ระบบ
- ดูรายการการ์ดสะสมและรายละเอียดสินค้า
- ค้นหาและกรองสินค้าตามหมวดหมู่
- เพิ่มสินค้าและจัดการตะกร้าสินค้า
- ยืนยันการสั่งซื้อและดูประวัติคำสั่งซื้อ
- ออกจากระบบ

### ผู้ดูแลระบบ (Admin)
- เข้าสู่ระบบด้วยบัญชีผู้ดูแล
- เพิ่มสินค้าใหม่และอัปโหลดรูปภาพจากคอมพิวเตอร์
- แก้ไขข้อมูลสินค้า
- ซ่อนหรือแสดงสินค้าในหน้าร้าน
- ตรวจสอบจำนวนสมาชิก สินค้า และคำสั่งซื้อ

## 5. Technologies (เทคโนโลยีที่ใช้)

- **HTML5:** สร้างโครงสร้างหน้าเว็บไซต์
- **CSS3:** ตกแต่งและจัดรูปแบบหน้าเว็บไซต์
- **JavaScript:** ควบคุมการทำงานและจัดการ DOM
- **Node.js:** ใช้รัน JavaScript ฝั่งเซิร์ฟเวอร์
- **Express.js:** สร้างเซิร์ฟเวอร์และจัดการ Routing/API
- **MySQL:** จัดเก็บข้อมูลสมาชิก สินค้า และคำสั่งซื้อ
- **Cookie:** เก็บ Session ID ของผู้ใช้ในเบราว์เซอร์
- **Session:** จดจำสถานะการเข้าสู่ระบบและข้อมูลตะกร้าสินค้า
- **bcryptjs:** เข้ารหัสรหัสผ่านก่อนบันทึกลงฐานข้อมูล
- **mysql2:** เชื่อมต่อ Node.js กับ MySQL
- **XAMPP/phpMyAdmin:** ใช้เปิดและจัดการฐานข้อมูล MySQL

## 6. วิธีติดตั้ง

1. ติดตั้ง Node.js และ XAMPP
2. เปิด Apache และ MySQL ผ่าน XAMPP โดยระบบนี้ต้องใช้ MySQL
3. เปิด phpMyAdmin ที่ `http://localhost/phpmyadmin`
4. เลือก Import และนำเข้าไฟล์ `sql/online_card_shop.sql`
5. เปิด PowerShell ที่โฟลเดอร์ `Online-Card-Shop`
6. ตรวจสอบการตั้งค่าฐานข้อมูลในไฟล์ `.env` ให้ชื่อฐานข้อมูลตรงกับ `online_card_shop` และตั้งค่า Username/Password ให้ตรงกับ MySQL ในเครื่อง
7. ติดตั้งแพ็กเกจด้วยคำสั่ง `npm install`

## 7. วิธี Run

1. เปิด XAMPP และเริ่ม MySQL
2. เปิด PowerShell ในโฟลเดอร์ `Online-Card-Shop`
3. พิมพ์คำสั่ง `npm start`
4. เปิดเว็บเบราว์เซอร์และเข้า `http://localhost:3000`
5. สมัครสมาชิกเพื่อทดลองใช้งานในฐานะ User หรือเข้าสู่ระบบด้วยบัญชี Admin ที่มีอยู่ในฐานข้อมูล
